# Titanic Survival Prediction – Data Cleaning Project

## Objective
Perform data cleaning and preprocessing on the Titanic Dataset.

## Tasks Completed
- Loaded dataset using Pandas
- Displayed dataset information using .info()
- Generated statistics using .describe()
- Handled missing values using median and mode imputation
- Encoded categorical variables using LabelEncoder and One-Hot Encoding
- Visualized age distribution using Seaborn and Matplotlib
- Exported cleaned dataset to Titanic_Cleaned.csv

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Output Files
- Titanic_Cleaned.csv
- Titanic_Data_Cleaning.ipynb
